ApplyRules
    initial_states
        1. transformfortensorization: reindex + transformlayout + blockize 变换为TensorCore可识别的结构
        2. MMATileLoopNest/TileLoopNest: 按SSSRRSRS结构多级分块，绑定blockIdx/threadIdx
        3. TransformIntermediateOutputLayout: 仅WMMA将输出buffer重排为WMMA packed格式
        4. AddWriteReuse: 基类的cache_write 写缓冲到shared memory
        5. AddWriteReuseTensorCore: 写回wmma.accumulator mma.matrixC, 绑定threadIdx.y
        6. MAAAddReadReuse/AddReadReuse: 读缓存A/B到shared memory (MMA 用 ReadAt, WMMA 用 CacheRead+ComputeAt)
        7. AddReadReuseTensorCore: 读fragment: shared → wmma.matrix_a/b, Tile+Blockize+Annotate
        8. AddSoftwarePipelie: 双缓冲 + 软件流水线 prefetch 注解

Step 4: ApplySubRules 流水线执行过程

[阶段1] TransformForTensorization
原始循环：for i in [0,128): for j in [0,128): for k in [0,128):
    C[i,j] += A[i,k] * B[k,j]

① ReIndex：创建中间 reindex block
    tensor_core_reindex_A: A_reindex[i,k] = A[i,k]
    tensor_core_reindex_B: B_reindex[k,j] = B[k,j]
    tensor_core_reindex_store: C_reindex[i,j] = C[i,j]

② TransformLayout：按 mapping_info 重排 buffer 维度
    A_reindex 的访问模式变换为 wmma.matrix_a 的 packed layout

③ TransformBlockLayout：重排 Block 的迭代顺序
    使 i,j,k 的顺序与 WMMA 期望的 m,n,k 对齐

④ TileWithTensorIntrin：将 i[0:128] 切成 [..., 16]
                        将 j[0:128] 切成 [..., 16]
                        将 k[0:128] 切成 [..., 16]
    返回最内层 16×16×16 的循环起始点 loop_rv

⑤ Blockize(loop_rv)：将 16×16×16 内层合并为一个 Block
    新的 block_rv 对应一次 WMMA 计算

⑥ Annotate:
    meta_schedule_auto_tensorize = "wmma_sync_16x16x16_f16f16f32"
    meta_schedule_auto_tensorize_init = "wmma_fill_16x16x16_f32"
    warp_execution = 1

[阶段2] TileLoopNest（SSSRRSRS → 3空间级+2规约级）
循环：for i_outer in [0,8): for j_outer in [0,8): for k_outer in [0,8):
        ...一个 WMMA 计算 block...

按 "SSSRRSRS" 分块：
S0: i 分成 [1, 2, 4] → [blockDim=1, warp=2, frag=4] → fused → bind blockIdx.x
S1: j 分成 [1, 2, 4] → fused → bind blockIdx.y
S2: (i_frag, j_frag) → bind threadIdx.y
R0: k 分成 [4, 2]    → outer k tile (走 shared memory)
R1: k 分成 [...]     → inner k tile (走 fragment)
S3: 最内层 spatial
R2: 最内层 reduce

重排后循环结构（SSSRRSRS）：
for bx (blockIdx.x):
    for by (blockIdx.y):
    for ty (threadIdx.y):
        for k0:          ← R0
        for k1:        ← R1
            for s_inner: ← S3
            for r_inner: ← R2
                wmma_block(16×16×16)

[阶段3] TransformIntermediateOutputLayout（WMMA专有）
将 accumulator buffer C 从 [M, N] 重排为：
    [warp_m, warp_n, frag_m, frag_n, elem_m=16, elem_n=16]
这是 WMMA 的标准 packed accumulator 格式

[阶段5] AddWriteReuseTensorCore
CacheWrite(C_block, 0, "wmma.accumulator"):
    创建 C_wmma buffer，形状 [2, 2, 16, 16]（每个 warp 持有的 fragment）

重排写回循环：
    for k_outer (i1'):    ← 一次只搬一行 fragment
    for ty (fused i0,j0): ← bind threadIdx.y
        for j1, elem_m, elem_n:
        shared_mem = wmma.accumulator

Blockize 最内 2 层 → annotate store_intrin = "wmma_store_16x16x16_f32_shared"

[阶段7] AddReadReuseTensorCore
CacheRead(A_reindex, 0, "wmma.matrix_a"):
    A_shared → A_fragment (wmma.matrix_a)
    ComputeAt 到 k1 层
    TileAndAnnotateTensorize → annotate "wmma_load_16x16x16_f16_a"

CacheRead(B_reindex, 1, "wmma.matrix_b"):
    B_shared → B_fragment (wmma.matrix_b)
    annotate "wmma_load_16x16x16_f16_b"

StorageAlign(A_shared, dim=-2, factor=32, offset=8):
    避免 shared memory bank conflict（float16 对齐）

[阶段8] AddSoftwarePipeline（如果启用）
对 k0 层（外规约）添加双缓冲注解：
    manifest_shared_memory_local_stage = 1
    double_buffer_scope = 0

对 k1 层（内规约）添加流水线注解：
    software_pipeline_stage = [0, 0, 1]
    # stage 0: load fragment, stage 1: compute
    software_pipeline_order = [0, 1, 2]

效果：预加载下一个 tile 的同时计算当前 tile，隐藏 shared→register 的延迟
